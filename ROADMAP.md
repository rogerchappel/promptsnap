# Roadmap

## 0.1 MVP

- Local config and prompt discovery.
- Redaction-aware deterministic snapshots.
- Approximate token budget assertions.
- Markdown and JSON summaries for humans, CI, and agents.
- Fixture-backed test and smoke coverage.

## 0.2 Candidates

- Snapshot prune command.
- JSON schema for `promptsnap.config.json`.
- GitHub Actions annotation output.
- Richer include/exclude patterns.

## Non-goals

- Hosted LLM evaluation.
- Remote prompt storage.
- Telemetry.
